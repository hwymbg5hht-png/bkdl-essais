# BKDL Essais

Web app iPhone pour pointer les cours d'essai du Bujinkan Kitamori Dôjô Lille,
reliée au classeur Google Sheets de suivi par un script Google Apps Script.

- `docs/` : la web app publiée sur GitHub Pages
- `apps-script/` : le script Google (`Code.gs`, `Logique.gs`) à coller dans l'éditeur Apps Script
- `tests/` : tests automatiques, à lancer avec `npm test`

Le PIN, l'identifiant du classeur et l'adresse du script ne sont jamais dans ce dépôt.
